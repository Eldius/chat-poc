## keybindings

| Key | Action |
|-----|--------|
| `Enter` | Send message |
| `Ctrl+S` | Export chat to Markdown file |
| `Ctrl+H` | Toggle help |
| `Esc` | Close popup / Quit |
| `Ctrl+C` | Quit |
| Mouse wheel | Scroll chat |
